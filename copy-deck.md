# Marci.RMT — Copy Deck

Every piece of editable text on the site, in one place. The copy editor is built from this file.

## How it works

- **Edit in the copy editor, not here.** It shows each page as it looks and lets you type straight onto it. This file is where it gets its block ids.
- **`###` lines are block ids.** The editor saves your edits under them and I use them to put your wording back in the right spot. Don't rename them.
- **`YOURS`** marks text already in your own words. The editor shows it with a green bar.
- **`NOTE:` lines are mine.** Either a flag from the key below, or a heads-up about something I changed in the restructure.
- **Blank means delete.** Clear a block in the editor and I'll remove that element when I merge.

## Flag key

| Flag | Meaning |
|---|---|
| `T1` | "X, not Y" / "rather than" contrast reflex, the loudest tell |
| `T2` | Short-fragment cadence used as rhythm |
| `T3` | Three-beat list (tricolon) |
| `T4` | Bent to fit the italicised-headline design pattern |
| `T5` | Authenticity insistence ("genuine", "actually", "real", "honest") |
| `T6` | Copy describing its own tone |
| `T8` | Claims experience you don't have yet. Needs your call, not just a reword |
