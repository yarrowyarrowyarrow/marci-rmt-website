# Marci.RMT — Copy Deck

Every piece of prose on the site, in one place, stripped of markup.

## How to use this

- **Edit the copy in place.** Rewrite, cut, leave alone — whatever you want.
- **Lines starting with `NOTE:` are mine.** They flag what I'd change and why. Ignore them or delete them; I don't read them back.
- **Do not change the `###` heading lines.** That's the ID I use to put your text back in the right place. Everything else is fair game.
- **Blank means delete.** If you clear a block's text entirely, I'll remove that element from the page.
- Send the file back when you're done and I'll merge it into the HTML.

## Flag key

| Flag | Meaning |
|---|---|
| `T1` | "X, not Y" / "rather than" contrast reflex — the loudest tell |
| `T2` | Short-fragment cadence used as rhythm |
| `T3` | Three-beat list (tricolon) |
| `T4` | Bent to fit the italicised-headline design pattern |
| `T5` | Authenticity insistence ("genuine", "actually", "real", "honest") |
| `T6` | Copy describing its own tone |
| `T8` | Claims experience you don't have yet — needs your call, not just a reword |
| `DUP` | Near-duplicate of another block |

Blocks with no flag are, in my read, already fine. Most of the site is.
